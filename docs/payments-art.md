# 美術史ラボ：有料範囲とStripe設定

同梱データは模擬試験1〜8の680問。模擬試験1・2は無料、3〜8はプレミアム会員向けです。6〜8は提供原稿を保持して登録を準備し、本番DBへの追加・画面公開は未実施です。将来の準備中回は `exam.upcoming_sets` に分離します。静的サイドバーとトップでは問題・一覧APIを呼びません（全ページ共通の認証確認を除く）。

価格はユーザー指定の税込総額500円・日本円・買い切り・自動更新なしです。Stripe TaxをCheckoutで有効化します。サーバーは金額/通貨/one_time/本番モードに加えてPriceの `tax_behavior=inclusive` を検査し、税抜きPriceによる追加請求を防ぎます。購入戻り画面では資格を付与せず、署名済みWebhookを金額/Price/利用者/支払状態と照合して処理します。部分返金は資格を維持し、全額返金/異議申立ては既存の失効処理へ従います。

販売者情報はユーザー指定の世界史ラボの公開情報を同じ開示方針で使います。値と専用APIキー・Webhook署名は非公開環境設定のみへ保存し、Git/画面/ログへ出しません。

Stripeの対象はユーザー選択の本番アカウント「misatoの地歴ラボ」。美術史ラボ専用の商品/Price/Webhookを使用し、他サービスの既存商品・キー・税登録・アカウント既定値は変更しません。本番APIキーはユーザーが専用キーを作成し、非公開設定へ保存します。販売開始はキー/署名/Price/販売者情報の整合が取れ、API・画面が同じ無料境界になった後に行います。

2026-11-08時点の確認：Stripe Tax設定はactive、日本の税登録はactive。ユーザー指定の自習型Web学習区分 `txcd_20060058` を商品へ設定済み。日本の住所を使う請求previewで総額500円（税45円）を確認し、専用キーで作成した未払Checkoutは確認後に即失効しました。Webhookは無効、Fly設定はステージのみ、販売受付は停止中です。実請求・本番カード決済のテストは行っていません。Stripe側リソースの作成/配信状況は `docs/verification.md` の最新記録を参照してください。

検証：単体211件、合成データの隔離DBで決済・返金・資格22件、PC/SP静的導線2件と有料直接URL2件。API401が匿名状態の世代を更新し続ける循環も修正しています。Stripe実環境の確認はこれらの合成テストと区別します。
