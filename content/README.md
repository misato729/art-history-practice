# 模擬試験1〜8の問題データ

サイト用の`questions.json`には、試験番号1〜8の「模擬試験1」〜「模擬試験8」、計680問を収録しています。各回は美術史80問と知識・情報の活用5問の85問、全問4択・正答一つです。本文・図版・表・解説・出典を含みます。

各回の `mock-exams/mock-NN/questions.json` は、全8回の問題データを模試ごとに取り出したものです。改稿履歴は [編集差分](editorial/figure-history-20261111.json)、旧版の冊子は [模試1〜5の原稿・PDF](mock-exams/README.md) で確認できます。

## 形式と参照範囲

- 各回60分、全85問。実践問題10問・30分は含みません。サイトは1問ずつ採点する演習で、一括受験セッションは含みません。
- 全問4択は本サービスの編集上の構成です。公式問題集の活用には選択肢数の異なる例もあり、公式の固定形式とは説明しません。
- 各回の分野配分は西洋41・日本25・現代5・東洋3・工芸デザイン4・美術館2・活用5。模試1〜5の初版では、難度を基礎19・標準53・発展13に配分しました。実際の知識・判断・近接誤答・図版と読む量を比較し、受験者による統計的な等化とは区別します。
- 全8回の通常問題640問のうち138問で作品図版または図表を用います。作品135点と図表6点を配置し、同一の作品・図表は一度だけ使用します。図版の制作背景・作者・流派・図像など、美術史の知識を問います。
- 保護期間が残る現代作品の図版を扱わないため、識別練習の範囲には限界があります。本試験の実測難度・合格点・所要時間の再現とは説明しません。
- 各問の`source_text`と編集メタデータに根拠を記録し、図版の出典と利用条件は既存の作品台帳と[追加作品の台帳](editorial/figure-history-assets.json)に記録しています。[通常問題の図版照合](../scripts/check-ordinary-figures.mjs)では、所蔵館の作品番号と配信用画像の内容も確認します。
- 提供原本は`past-exam/`・`textbook.*`、作業資料は`local-only/`などにローカル保管し、Git・Docker・外部公開へ含めません。

## 初期取込

初期取込後の問題の正本はDBです。新しい空DBには680問・2720選択肢を取り込みます。JSONの更新は既存DBを自動更新せず、リセット・上書き・自動削除を行いません。

既存DBへの反映は、[カスタマイズ手順](../docs/customization.md)に沿ってバックアップと対象DBを確認してから別途行います。今回の検証、Git送信と公開の実施範囲は[検証記録](../docs/verification.md)へ記録します。
