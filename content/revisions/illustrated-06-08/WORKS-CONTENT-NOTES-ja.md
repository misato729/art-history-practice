# Works引き継ぎ：模試6・7・8の追加原稿

## 役割と変更範囲

作問はChat、コード・データ変換・DB反映・テストはWorksが担当する分担です。
対象は `misato729/art-history-practice` に新設する模試6・7・8です。
各85問（通常1〜80、共通資料を使う活用81〜85）、各340選択肢です。
**既存の模試1〜5の問題・採点・履歴・お気に入りを変更しないでください。**
本パッケージは原稿であり、DBダンプ、実行用SQL、マイグレーション、アプリ実装パッチではありません。

## 読む順序

`README-ja.md` → 各回 `exam.json` → `asset-manifest.json` → `SOURCE-POLICY-ja.md` → `QA-ja.md`。
内容を確認するには各回の `review.html` または `questions.pdf`・`answers.pdf` を使います。

## JSONとデータ変換

- `exam_number` は6・7・8。`question_number` は各1〜85です。
- `content_key` と `choice_key` はこの原稿内の安定した識別子であり、本番DBの主キーではありません。
- `choices[].label`、`display_order`、`is_correct`、`explanation`、`correct_label` を一緒に扱ってください。
  表示順を変える場合は正答と誤答理由の紐付けを保持します。
- `sources` は機械処理用、`source_text` は表示用です。印刷ページとPDFページを取り違えないでください。
- `major_category_code`・`category_code` は原稿上の分類です。現行DBの分類マスターと整合させ、不明なら照合結果を示してください。
- `topic` は編集・解説用の見出しです。解答前に表示するとヒントになるため、既存アプリの見出しとして無条件に出さないでください。
- `difficulty_estimate` と `cognitive_task` は編集用メタデータです。統計的に測定された難度ではありません。
- `supplementary_blocks` など任意の原稿情報を黙って落とさず、利用する項目を明確にしてください。

## 図版と共通資料

`questions[].images` の `file` は各模試フォルダーから見た相対パスです。例：`../assets/mock03-img-01.jpg`。
`asset-manifest.json` の `file` はパッケージルートからのパスです。例：`assets/mock03-img-01.jpg`。
作品画像の古い `mock02`・`mock03` などの名前は出所を示す既存識別子であり、旧模試を更新する指示ではありません。
既存アセットと同じ名前の場合はSHA-256を確認して再利用し、別内容なら衝突しないパスに配置してください。
画像を新しいパスへ配置した場合は、JSONの参照も一貫して更新します。

各回 `shared_materials` に、問81〜85で使う資料・図版4点・表・注記が入っています。
設問の `shared_material_id` と紐付け、1問ずつの演習でも必要な資料を常に参照できるようにしてください。
通常問題には共有資料を一律に後付けしません。不要な定型導入文・資料枠を復活させないでください。
二図比較問題はA/Bなどのラベルと並び順を保持し、画面幅によって縦並びにしても対応が変わらないようにします。
画像は拡大可能にし、色や細部を問う設問で読める大きさにしてください。別作品への無断差し替えは禁止です。
解答前の画像キャプション・alt・ファイル名表示から作者等の正答が漏れないよう、編集上の用途を分離してください。
解答後のクレジットには作品情報・提供元・利用条件の記録を保持してください。
